RULE 00 / BEFORE INTERVIEW

最初に、絶対に守ってほしいルール

TALK SCRIPT 質問されたら、まず答える。

今日は面接について、いろいろなことを話します。

質問の意図とか、答え方とか、自分の経験の伝え方とか、覚えてほしいことはたくさんあります。

でも、その前に。全部忘れてもいいとは言わないけど、まずこれだけは絶対に覚えて帰ってください。

質問されたら、まず答える。

これが、面接の受け答えで守ってほしい大前提のルールです。

たとえば、「高校生活で最も力を入れたことは何ですか？」って訊かれたとする。

そこで、「1年生のときに先生から資格を勧められて、そのあと友達と勉強を始めて……」って話し始めると、聞いている側は途中まで、「で、結局この子は何を頑張ったんだ？」って分からないんです。

だから、まず答える。

「私が高校生活で最も力を入れたことは、電気工事士の資格取得です。」

ここまで言ってから、「なぜ取り組んだのか」「どう頑張ったのか」「そこから何を学んだのか」を話せばいい。

順番は、結論 → 理由 → 具体的な経験です。

これは、面接でそれっぽく話すためのテクニックじゃありません。

相手から訊かれたことに、ちゃんと答えるための基本です。

どれだけ良い経験をしていても、話したいことをたくさん持っていても、質問に対する答えが最初に出てこなければ、相手には伝わりにくい。

だから面接練習中、私が「今、まず答えられてた？」って訊くことがあると思います。そのときは、このルールを思い出してください。

質問されたら、まず答える。
結論を言ってから、理由を話す。

まずはこれを守る。その上で、質問の意図を考えたり、自分の経験を深く話したりしていこう。

面接のいろいろな技術は、その土台の上に乗ります。

REVIEW TALK / AFTER INTERVIEW

面接官は、結局なにを知りたいのか

模擬面接が終わった直後、生徒へ問いを与えながら進める感想戦用TALK。答えを先に教えず、生徒自身に一度考えてもらってから説明へ進む。

BEFORE WE START まず、私がどんな立場からこの話をするのか

これから面接について話す前に、私がどういう経験からこの話をしているのかだけ、少し説明します。

私は工業高校卒業後、理科大へ進学し、就職活動では一度失敗しています。

その後、自分で会社を立ち上げ、経営や人事に携わる中で、企業側の面接官・採用する側を経験しました。

その後は教育の世界へ進み、専門学校で教員・総務として勤務し、ここでも私立学校側の面接官・採用する側を経験しています。

現在は工業高校の教員として、高校生の就職・進学に関わっています。

つまり私は、面接を「受ける側」も「採る側」も経験してきました。

これから話すことは、単に「面接ではこう答えればいい」という話ではありません。

私自身が両方の立場を経験してきた中で、「採る側は、面接で何を知ろうとしているのか」について考えてきたことを、みなさんに伝えます。

HOW TO USE 問いを投げる → 生徒の答えを待つ → 「説明を開く」

このページは生徒に見せながら使ってもよい。ASKのところでは一度スクロールを止め、生徒の言葉を待つ。

ASK 01

今日された、あらゆる質問の裏側に共通している「二つの意図」って、何だと思う？

今日、いろんな質問をされたよね。
志望動機、高校生活、長所や短所、失敗した経験、課題研究、将来のこと。

質問の内容は全部違います。
でも、すべての質問の裏側には、その質問をした面接官の「意図」があります。

つまり、「この質問を通して、あなたの何を知りたいのか？」ということです。

私は、面接でされるさまざまな質問の裏側にある意図は、突き詰めると二つに集約できると考えています。

生徒が答えたら、説明を開く

答えは、「定着性」と「活躍性」です。

RETENTION

定着性とは？

「この人は、ここに入ったあとも続けてくれそうか？」

会社は、新しく入った人を育てるために、お金も時間も人も使います。 仕事を教える。研修をする。先輩が時間を使う。経験を積ませる。

大学だって似ています。先生が教え、設備を使い、研究や活動の機会を用意する。

だから採る側・迎え入れる側としては、 「この人に時間や労力を使っても、すぐにいなくならないだろうか？」 「本当にここを選んでいるのだろうか？」 を知りたい。

ただし、定着性は「絶対に辞めません！」と言えばいい、という話ではありません。

思っていたことと違ったとき。希望どおりにならなかったとき。 人間関係や勉強、仕事で困ったとき。 そんなときにも、考える、相談する、工夫する、向き合う。

そういうことができそうな人なのか。そこまで含めて見られています。

GROWTH

活躍性とは？

「この人は、ここに入ったあとに成長してくれそうか？」

高校生の時点で、完成された社員や大学生である必要なんてありません。今できないことがあって当然です。

だから大事なのは、今どれだけ完成しているかではなく、これからどう伸びていきそうか。

分からないことを学べるか。失敗したときに修正できるか。 周囲の人と協力できるか。自分から考えて動けるか。経験から何かを学べるか。

そういう受け答えや過去の経験から、 「この人は入ったあと伸びそうだな」 「将来、力を発揮してくれそうだな」 と思ってもらえるか。

これが活躍性です。

ASK 02

だったら、直接聞けばよくない？

「あなたは、うちに定着してくれますか？」
「あなたは、入ったあと活躍してくれますか？」

こうやって直接聞けば早いよね。
なのに、なぜ面接官は「志望理由は？」「失敗した経験は？」「長所は？」「課題研究では何をした？」と、 いろんな質問を遠回しにしてくるんだと思う？

生徒が答えたら、説明を開く

直接聞いたって、ほとんどの人が「はい」と答えるからです。

「私はすぐ辞めると思います」「たぶん成長しません」なんて答える人は、まずいないよね。

つまり、本人が「私は大丈夫です」と言っただけでは、信用できる材料として弱い。

だから面接官はいろいろな角度から質問します。 過去に何をしてきたのか。失敗したときどうしたのか。何を大切にしているのか。 なぜここを選んだのか。人とどう関わってきたのか。これからどうなりたいのか。

そして回答を重ねながら、 「この人の話は本当に信用できそうか？」 「ここで続けてくれそうか？」 「これから伸びてくれそうか？」 を確かめているわけです。

KEY MESSAGE

だから、面接で本当に大事なのは何か

POSSIBILITY あなたの「可能性」を感じてもらうこと。
TRUST あなたを「信用」してもらうこと。

今の自分を必要以上に立派に見せることではありません。 「この人なら、これから成長しそうだ」と思ってもらう。 そして「この人が話していることなら、信じてもよさそうだ」と思ってもらう。

では、そのために、こっち側ができることは何か。

HONESTY 素直であること。
OWN WORDS 熱意を、自分の言葉で伝えること。
HONESTY

「素直であること」

分からないのに、分かったふりをしない。失敗したことを、なかったことにしない。 自分の弱いところも認める。助けてもらったことも認める。

でも、「だから仕方ありませんでした」で終わらず、 そこから何を考えて、どうしようとしているのかまで話す。

素直というのは、何でも相手の言うことを聞くという意味ではありません。

自分にも、相手にも、誠実であること。

私はそう考えています。

OWN WORDS

「熱意を、自分の言葉で伝えること」

立派な文章じゃなくていいです。少しくらい言葉に詰まってもいい。

ネットで調べた綺麗な志望動機を暗記して話すより、 「自分はこういう経験をした」「だから、こう思うようになった」「だから、ここでこれをやりたい」 と、自分の中にあるものを自分の言葉で話した方が、ずっと伝わります。

なぜなら、その言葉には、その人自身しか持っていない経験が乗るからです。

それが熱意になって、それが信用にもつながります。

REVIEW

じゃあ、今日の面接をもう一度振り返ってみよう

ここから大切なのは、「あの質問には、この回答をすればよかった」だけで終わらせないことです。

なんで、あの質問をされたんだろう？

定着性の何を確認しようとしていた？

活躍性の何を確認しようとしていた？

自分の回答から、それは相手に伝わっただろうか？

ここまで考えると、面接で聞かれる質問を全部暗記しなくてもよくなります。 知らない質問が飛んできても、「この質問で、相手は自分の何を知りたいんだ？」と考えられるからです。

それができれば、自分の中にある経験や考えを使って、その場で自分の言葉を組み立てられる。

私は、それが面接で求められる本当の意味での「コミュニケーション能力」だと思っています。

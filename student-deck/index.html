00 / BEFORE YOU START

臨時休校で
面接練習ができなくなったみなさんへ

就職試験は、もうすぐそこまで来ています。

学校で一緒に練習できない間にも、できることはあります。

そのために、この自主練習用のデッキを用意しました。

このサイトだけで面接が完成するわけではありません。

でも、今日できる練習はできます。

答えを覚えるためではなく、

「なぜ、この質問をされた？」を考えるために使ってください。

01 / HOW TO USE

使い方は、5つだけ。

  1. 01

    QUESTIONを見る

    質問を一度だけ読みます。

  2. 02

    画面から目を離す

    スマホを見ながらではなく、実際の面接を想像してください。

  3. 03

    必ず、声に出して答える

    頭の中で言えることと、実際に口から出せることは別です。

  4. 04

    COMBOにも答える

    本番では、一つの答えからさらに掘り下げられることがあります。

  5. 05

    意図を考えてからREVIEWを開く

    先に答えを見るのではなく、自分で「なぜ聞かれた？」を考えます。

02 / IMPORTANT

これだけは、守って。

RULE 01

答えを先に見ない。

REVIEWは、実際に答えたあとで開いてください。

RULE 02

頭の中だけで終わらせない。

必ず声に出してください。うまく言えない場所こそ、本番前に見つけたい場所です。

RULE 03

文章を丸暗記しない。

覚えるのは答えではなく、「相手は何を知りたいのか」という考え方です。

03 / TWO AXES

質問の裏側にある、二つの視点。

面接官が知ろうとしていることは、細かく見ればさまざまです。 このデッキでは、それを考えるための道具として大きく二つに整理します。

定着性

この人は、ここで続けていけそうか。

会社や仕事を理解して選んでいるか。予定外のことや人間関係のズレが起きたとき、どう向き合う人なのか。

活躍性

この人は、ここで成長・活躍できそうか。

自分で考える、学ぶ、工夫する、協力する、失敗から修正する。そんな行動ができそうか。

正解を当てるゲームではありません。
「この質問は、相手が何を知るために聞いたのか？」と考えるために使ってください。

04 / EMPLOYMENT DECK

就職面接・直前10枚。

1枚ずつ。声に出す。

05 / FINISH

10問、お疲れさまでした。

全部きれいに答えられましたか？

……たぶん、そうではないと思います。

でも、それで大丈夫です。

今、言葉に詰まった質問や、REVIEWを読んで「もう少し考えたい」と思った質問は、 本番までに考える場所が見つかった質問です。

LAST TASK

10問の中から、うまく答えられなかったものを3問だけ選んでください。

REVIEWを閉じて、もう一度その質問とCOMBOに声を出して答えてみましょう。

完璧な文章を作る必要はありません。

本番で必要なのは、覚えてきた文章を正確に再生することではありません。

「なぜ、この質問をされた？」

と考え、

自分の経験や考えの中から、
自分の言葉で返すこと。

それができれば、この練習には意味があります。

答えを覚えるのではなく、問いの裏側を読む。
本番でも、対話してきてください。
